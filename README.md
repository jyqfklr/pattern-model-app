# 模式-模型行动系统（Pattern-Model Action System）

把「模式-模型理论」（Pattern-Model Theory v1.0）编译成可执行计划与每日日程的纯前端应用。
输入你想攻克的领域（或粘贴你的教材目录 / 材料清单），应用会生成按时间与周期组织的行动框架，并把任务铺到每一天。

## 理论基础

- **分层认知**：具身无意识 → 前意识 → 自我-世界模型 → 意识（元模式仲裁）＋ 扩展环境
- **预测误差驱动学习**：一切学习都是预测误差的缩减——预测 → 暴露 → 误差 → 持有（24–72h）→ 实验 → 更新
- **核心原语**：双缓冲流水线 · 预测误差飞轮 · 模式真空协议 · 身份容器化 · 三波节律（晨预载 / 日执行 / 晚审计）

## 功能

- **① 领域迁移 · 行动框架**
  - 六大内置领域（学习 / 投资 / 竞赛 / 科研 / 工作 / 关系）+ 自定义领域
  - 每个领域内置 12 周详细行动纲领，按周期长度（7–365 天）自动缩放
  - 模糊目标检测与具体化助手（勾选验收标准并入目标）
  - 数字目标自动计算每周配速（如"90 天背 3000 单词"→ 每天约 33 个）
  - 上传文件提取材料条目（txt / md / csv / pdf / docx，本地解析），按天分配：第一遍新学 → 第二遍检验
- **② 每日日程 · 提醒**
  - 三波节律任务，执行内容随日期逐天递进（周内 7 天各有重点）
  - 未完成任务自动结转到次日，补记到原日期
  - 多计划并行，独立打卡与进度
- **③ 社区 · 分享**
  - 一键生成分享码（计划框架 + 进度快照，lz-string 压缩，本地编码）
  - 粘贴他人分享码即可查看、收藏到社区墙、克隆为自己的计划
  - 社区广场：本仓库的 [Discussions](../../discussions) —— 把分享码发到这里即可互通有无

## 隐私与架构

纯前端、纯离线：所有数据存于浏览器 localStorage，无任何服务器、无任何网络请求、不消耗任何 API token。
PDF 解析（pdf.js）、Word 解析（mammoth）均在浏览器内完成。

## 本地运行

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建 → dist/
npm run preview    # 预览生产构建
```

## 部署

`dist/` 是纯静态站点，可直接部署到 GitHub Pages / Vercel / Netlify / 任意静态托管。

```bash
npm run build
# 例如 GitHub Pages：把 dist/ 内容推送到 gh-pages 分支即可
```
